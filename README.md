# SNM Arch Linux Dotfiles

Personal dotfiles repository for my Arch Linux desktop running Hyprland.

## Configurations

- **Hyprland:** Lua configuration, window rules, keybindings, animations, monitors and scripts.
- **Waybar:** Status bar configuration, styles and custom scripts.
- **Kitty:** Terminal configuration.
- **Rofi:** Wi-Fi and Bluetooth menus.
- **Wofi:** Application and power menus.
- **Dolphin:** File manager preferences.
- **KDE:** Shared application settings (`kdeglobals`).
- **SDDM:** Custom login screen theme.
- **Zsh:** Shell configuration and Powerlevel10k prompt.
- **Wallpapers:** Desktop and lock screen backgrounds.
